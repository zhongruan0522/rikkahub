## 上游合并对照记录

### PR #18（上游 `41d77f1e`，合并提交 `d285ba2c`）

- **数据库版本重排**：本仓库 v33 为删除 `translation_history`（`AutoMigrationSpec`）；上游 v33（`message_node` 复合索引）与 v34（`workspaces.storage_mounts`）合并为手写 `Migration_33_34`；上游后续 `34 → 35` 迁移只要不涉及 `translation_history` 可直接沿用。
- **内置提供商**：`DefaultProviders.kt` 不引入上游推广渠道（AiHubMix、APIMart、随想AI网关、MaruCode、STA1N），只接入 `DEEPSEEK_PROVIDER_ID`；`DefaultProvidersTest` 保留本仓库版本。
- **路由**：`RouteActivity.kt` 只新增 `Screen.QuickStart`，不恢复 `Screen.SettingDonate`。
- **快速入门**：`QuickStartVM.setDefaultChatModel` 不写入已移除的 `translateModeId`，8 套 `strings.xml` 的 `quick_start_page_model_desc` 去掉「翻译模型」。
